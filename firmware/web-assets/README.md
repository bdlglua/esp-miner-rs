Ces ressources gzip correspondent au client Rust interne de `web/embedded-rust`, encore utilisé par les routes statiques du firmware. Elles sont conservées pour permettre une compilation du firmware sans chaîne WASM locale. Ce ne sont pas les fichiers d’AxeOS officiel. Reconstruction : `python scripts/build-embedded-web.py` depuis la racine. Voir `docs/status.md` pour le raccordement de l’application Angular officielle.
